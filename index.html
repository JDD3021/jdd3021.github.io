03 - Selected Projects

Ideas taken through to working software.

CardioBeat

Final-year project

An AI-assisted cardiac sound screening prototype. CardioBeat classifies heart sounds as Normal or Abnormal using deep learning (CNN-BiLSTM / CNN-LSTM) on MFCC features extracted from public heart sound datasets, aiming to support early screening in resource-limited settings. It is a decision-support prototype, not a diagnostic device.

  • Model results: 87.7% accuracy and 89.2% sensitivity, backed by exploratory analysis, a confusion matrix, and a fix for overfitting.
  • Delivered a demo mobile app, a FastAPI service, and a UML analysis document (use case, activity, sequence, and class diagrams).
  • Wrote the defense thesis and a 20-slide presentation, and ran a Google Forms survey with branching logic among healthcare professionals.
  • Python
  • Deep Learning
  • CNN-BiLSTM / CNN-LSTM
  • MFCC
  • FastAPI
  • Flutter
  • SQLite
  • UML

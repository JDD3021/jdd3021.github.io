The writing/article cards on the site look for an image at this exact path:

    assets/img/writing/violences-numeriques.jpg

Add a cover image for the article with exactly that file name and it
will appear automatically above the article card content. Until a file
is added, a placeholder icon is shown instead, so there is nothing else
to change in the code.

When you publish a new article, copy the whole <article> block in
index.html, add a new image with a matching file name, and update the
img src to point to it.

You can delete this text file once the photo is in place.
